╔══════════════════════════════════════════════════════════════════════════════╗
║                         UML CLASS STRUCTURE                                  ║
╚══════════════════════════════════════════════════════════════════════════════╝

    A proper UML class has 3 COMPARTMENTS:

    ┌─────────────────────────────────────────────┐
    │  1️⃣  CLASS NAME (with stereotype)           │  ← Top compartment
    ├─────────────────────────────────────────────┤
    │  2️⃣  ATTRIBUTES (data fields)               │  ← Middle compartment
    │     - privateField: Type                    │
    │     + publicField: Type                     │
    ├─────────────────────────────────────────────┤
    │  3️⃣  OPERATIONS (methods/functions)         │  ← Bottom compartment
    │     + publicMethod(): ReturnType            │     ⚠️ YOU ARE MISSING THIS!
    │     - privateMethod(param: Type): Type      │
    └─────────────────────────────────────────────┘
