# Professional Screenshot Annotation Guide - PowerPoint

## Step-by-Step Instructions for Creating Clean, Professional Annotations

### PART 1: Setup (5 minutes)

1. **Open PowerPoint**
   - Create a new blank presentation
   - Set slide size: Design → Slide Size → Custom (16:9 ratio)

2. **Insert Your Screenshot**
   - Insert → Pictures → Select your login screenshot
   - Resize to fill most of the slide
   - Center it on the slide

3. **Lock the Screenshot**
   - Right-click screenshot → Format Picture
   - Size & Properties → Lock aspect ratio ✓
   - This prevents accidental resizing

---

### PART 2: Create Numbered Circles (10 minutes)

1. **Insert Circle Shape**
   - Insert → Shapes → Oval
   - Hold SHIFT while dragging to create a perfect circle
   - Size: 0.35" x 0.35" (or 24px x 24px)

2. **Format the Circle**
   - Fill: Red (#DC2626 or RGB: 220, 38, 38)
   - Border: None
   - Right-click → Format Shape → Shadow: None

3. **Add Number**
   - Right-click circle → Edit Text
   - Type: 1
   - Font: Arial Bold, 12pt
   - Color: White
   - Alignment: Center (both horizontal and vertical)

4. **Create More Circles**
   - Copy the first circle (Ctrl+C, Ctrl+V)
   - Change numbers: 2, 3, 4, 5, 6, 7, 8, 9, 10
   - Arrange them temporarily on the side

---

### PART 3: Create Arrows (15 minutes)

**For Each Annotation:**

1. **Insert Arrow**
   - Insert → Shapes → Arrow: Curved Right
   - Draw from numbered circle to the UI element

2. **Format Arrow**
   - Line color: Red (#DC2626)
   - Line width: 2pt (for main steps) or 1.5pt (for helper elements)
   - For "Sign In" button: Use 3pt width
   - Arrow style: End arrow (→)
   - No shadow or effects

3. **Adjust Curve**
   - Click arrow → Yellow adjustment handle appears
   - Drag to create a gentle curve
   - Avoid sharp angles

**Arrow Placement Guide:**

```
Left Side (Main Steps):
③ → Select Your Role dropdown
④ → Username field  
⑤ → Password field
⑦ → Remember me checkbox
⑨ → Sign In button (thicker arrow)

Right Side (Helper Elements):
① → Welcome Back title
② → Subtitle
④ → Dropdown arrow icon
⑥ → Eye icon (show/hide)
⑧ → Forgot password link

Bottom:
⑩ → Contact administrator link
```

---

### PART 4: Create Text Labels (15 minutes)

1. **Insert Text Box**
   - Insert → Text Box
   - Draw a text box near the arrow end

2. **Add Label Text**
   - Type the label (e.g., "STEP 1: Select role")
   - Font: Arial, 10pt
   - Color: Dark gray (#1F2937)

3. **Format Text Box**
   - Fill: White with 80% opacity
   - Border: 1pt, Light gray (#E5E7EB)
   - Padding: 0.05" on all sides
   - No shadow

4. **Position Labels**
   - Place outside the screenshot when possible
   - Align with the arrow
   - Ensure no overlap with other labels

**Label Text for Each Number:**

```
① "System title"
② "Login instruction"  
③ "STEP 1: Select your role from dropdown"
④ "Click to expand role options"
⑤ "STEP 2: Enter your username (case-sensitive)"
⑥ "Show/hide password toggle"
⑦ "STEP 3: Enter your password (case-sensitive)"
⑧ "STEP 4 (Optional): Check to save login"
⑨ "Password recovery link"
⑩ "STEP 5: Click to login"
⑪ "Technical support link"
```

---

### PART 5: Create Legend Box (5 minutes)

1. **Insert Rectangle**
   - Insert → Shapes → Rectangle
   - Size: 2.5" x 1.5"
   - Position: Bottom left corner

2. **Format Rectangle**
   - Fill: White with 90% opacity
   - Border: 1pt, Gray (#9CA3AF)
   - No shadow

3. **Add Legend Text**
   - Insert → Text Box inside rectangle
   - Type:
     ```
     LEGEND
     ① - ⑪  Step numbers
     →      Indicates element
     STEP X Required action
     (Optional) Optional action
     ```
   - Font: Arial, 9pt
   - Color: Dark gray
   - Align left

---

### PART 6: Final Touches (5 minutes)

1. **Align Elements**
   - Select all left-side annotations
   - Format → Align → Align Left
   - Format → Align → Distribute Vertically

2. **Check Spacing**
   - Ensure consistent spacing between elements
   - No overlapping arrows or labels
   - All text is readable

3. **Group Annotations**
   - Select all annotation elements (circles, arrows, labels)
   - Right-click → Group
   - This prevents accidental movement

4. **Final Review**
   - Zoom to 50% - check readability
   - Zoom to 100% - check details
   - Print preview - ensure clarity

---

### PART 7: Export (2 minutes)

1. **Export as Image**
   - File → Save As
   - File type: PNG
   - Resolution: High quality (300 DPI)
   - Save

2. **Alternative: Export as PDF**
   - File → Export → Create PDF
   - Quality: High
   - This preserves vector quality

---

## PROFESSIONAL TIPS:

✓ **Consistency is Key**
  - Use the same arrow style throughout
  - Keep label formatting identical
  - Maintain consistent spacing

✓ **Less is More**
  - Don't over-annotate
  - Only label what's necessary
  - Keep labels concise

✓ **Readability First**
  - Test at different zoom levels
  - Ensure high contrast
  - Use readable font sizes

✓ **Professional Appearance**
  - No fancy effects
  - No decorative elements
  - Clean, technical style
