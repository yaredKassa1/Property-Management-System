DIAGRAM REQUIREMENTS:
===========================================

LAYOUT:
- Use left-to-right or top-to-bottom layout
- Group related classes together
- Minimize crossing lines
- Use orthogonal (straight) lines for associations

STYLING:
- Professional, clean appearance
- Use standard UML notation
- Class boxes with 3 compartments:
  1. Class name (bold, centered)
  2. Attributes (- for private, + for public)
  3. Operations/Methods (+ for public, - for private)
- Use stereotypes: <<Entity>>, <<Workflow>>, <<Audit>>
- Color coding (optional):
  * Entity classes: Light green (#E8F5E9)
  * Workflow classes: Light blue (#E3F2FD)
  * Audit classes: Light orange (#FFF3E0)

ASSOCIATIONS:
- Use proper UML notation:
  * Solid line for association
  * Diamond for composition (filled) or aggregation (hollow)
  * Arrow for navigability
  * Multiplicity at both ends (1, 0..1, 0..*, 1..*)
- Label relationships with verb phrases
- Show foreign key relationships
