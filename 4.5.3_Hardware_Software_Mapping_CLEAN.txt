4.5.3 Hardware/Software Mapping

Hardware/Software Mapping defines the allocation of software components to physical hardware nodes. The WDUPMS follows a three-tier deployment architecture with clear separation between client, application server, and database server.

═══════════════════════════════════════════════════════════════════════════════
NODE 1: CLIENT WORKSTATION
═══════════════════════════════════════════════════════════════════════════════

Hardware:
- Desktop, laptop, or mobile device with network connectivity

Software Components:
- Web Browser (Chrome, Firefox, Edge)
- Next.js Frontend (React UI Components)
- JWT Token Storage

Communication:
- HTTPS/REST API with JSON data format

═══════════════════════════════════════════════════════════════════════════════
NODE 2: APPLICATION SERVER
═══════════════════════════════════════════════════════════════════════════════

Hardware:
- Server-grade hardware or cloud VM
- Recommended: 8GB RAM, quad-core processor, 50GB storage

Software Components:
- Operating System: Linux (Ubuntu 20.04+) or Windows Server
- Runtime: Node.js 18+ with Express.js 4.18.2
- Process Manager: PM2 (production)

Deployed Subsystems:
1. User Management
2. Asset Management
3. Request Management
4. Procurement Workflow
5. Transfer Management
6. Return Management
7. Quality Assurance
8. Notification & Audit
9. Reporting & Dashboard

Supporting Services:
- JWT Authentication
- Email Service (Nodemailer)
- Scheduler (node-cron)
- Security Middleware (Helmet, CORS, rate limiting)

Communication:
- Inbound: HTTPS REST API (port 443/5000)
- Outbound: PostgreSQL (port 5432), SMTP (port 587)

═══════════════════════════════════════════════════════════════════════════════
NODE 3: DATABASE SERVER
═══════════════════════════════════════════════════════════════════════════════

Hardware:
- Dedicated database server or cloud instance
- Recommended: 16GB RAM, quad-core processor, 100GB+ SSD

Software Components:
- PostgreSQL 8.11.3+
- Sequelize ORM 6.35.2

Database Schema:
- 11 Tables: Users, Assets, Requests, Transfers, Returns, ProcurementWorkflows, 
  ProcurementInspections, Notifications, AuditLogs, TransferHistory
- Indexes, foreign key constraints, connection pooling

Communication:
- PostgreSQL protocol (port 5432) with SSL/TLS encryption

═══════════════════════════════════════════════════════════════════════════════
COMPONENT-TO-NODE ALLOCATION
═══════════════════════════════════════════════════════════════════════════════

Client Workstation (Node 1):
├── Web Browser
├── Next.js Frontend
└── JWT Token Storage

Application Server (Node 2):
├── Express Router
├── Middleware Stack
├── Controllers (8 components)
├── Business Services (8 components)
└── Supporting Services (4 components)

Database Server (Node 3):
├── PostgreSQL Database
├── 11 Tables with Relationships
└── Indexes and Constraints
